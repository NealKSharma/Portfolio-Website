# Personal Portfolio Website

Personal portfolio website for **Neal Kaushik Sharma** — Computer Science Student @ Iowa State University.

## Live
The website is hosted live at: **[https://nealks.netlify.app/](https://nealks.netlify.app/)**

## CI/CD & Deployment
Automated CI/CD pipelines are configured in this repository to automatically build and deploy new updates to Netlify whenever changes are pushed to the main branch.

## Built With
- **HTML5 & CSS3** (Vanilla CSS design system, responsive layouts, noise overlays)
- **JavaScript (ES6+)** (Dynamic menu interaction & typing effects)
- **Netlify** for continuous deployment & hosting
